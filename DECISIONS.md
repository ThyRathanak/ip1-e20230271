# Design Decisions

- 2026-10-24: Chose the Helpdesk Ticket Management System because its ticket lifecycle and two user roles fit the semester project scope.
- 2026-10-24: Chose User, Ticket, and Reply as the initial data entities because one user can create many tickets and one ticket can have many replies.
- 2026-10-24: Use Vue 3 with TypeScript and Vite for the frontend to follow the required course stack.
