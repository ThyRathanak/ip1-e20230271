# Helpdesk Ticket Management System

An individual Internet Programming I project for ITC, academic year 2026–2027.

## Description

A web application for submitting, tracking, and managing technical support tickets.

## Planned Features

- User and support-agent roles
- Ticket creation and management
- Ticket replies and status updates
- Search and filtering

## Technology Stack

- Frontend: Vue 3, TypeScript, Vite
- Backend: NestJS
- Database: PostgreSQL
- ORM: Prisma

## Run the Frontend

1. Install Node.js.
2. Open the `frontend/` directory.
3. Run `npm install`.
4. Run `npm run dev`.
